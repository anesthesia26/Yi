# 🏥 الموسوعة التخديرية السريرية الشاملة
# Anesthesia & ICU Master Workstation

منصة سريرية متكاملة وحديثة لأطباء التخدير والعناية المركزة، تجمع بين الذكاء الطبي والحسابات الدقيقة والبروتوكولات العالمية المحدثة.

## 📋 محتويات المشروع

```
مشروع كميل موقعي/
├── landing.html              # صفحة الهبوط الرئيسية
├── index.html                # صفحة تسجيل الدخول
├── app.html                  # التطبيق الرئيسي
├── css/
│   └── advanced-design.css   # نظام التصميم المتقدم
├── js/
│   ├── clinical-data.js      # قاعدة البيانات السريرية
│   └── clinical-engine.js    # محرك الحسابات السريرية
└── README.md                 # هذا الملف
```

### 💊 حاسبات الجرعات الدوائية
- حسابات دقيقة لأدوية الحث

- تعديل تلقائي للسمنة والعمر

- VCV (Volume Control)
- PCV (Pressure Control)

- تعديلات الفنتليتر الموجهة

- ACLS Protocol
- فرط الحرارة الخبيث
- تشنج الحنجرة
- الصدمة التأقية

### 📋 التقييم قبل العمليات
- مقياس Mallampati
- مؤشر RCRI
- مقياس STOP-Bang
- تصنيف ASA

## 💡 نصائح الاستخدام

### للحسابات الدقيقة
- تأكد من إدخال الوزن والطول بشكل صحيح
- استخدم الوزن المثالي (IBW) للسمينين
- تحقق من الجرعات قبل الإعطاء

### للطوارئ
- احفظ بروتوكولات الطوارئ في ذاكرتك
- تعرف على الخطوات الأساسية
- تدرب على الحالات الحرجة

### للتهوية
- فهم الأنماط المختلفة
- اعرف متى تستخدم كل نمط
- راقب البيانات الحيوية باستمرار
